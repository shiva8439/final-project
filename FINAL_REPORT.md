# Final Report: Virtual Contrast MRI with Uncertainty Quantification

## Executive Summary

This project presents a deep learning-based solution for generating contrast-enhanced MRI (T1CE) images from non-contrast modalities (T1, T2, FLAIR). The system addresses the clinical need for contrast-enhanced imaging without gadolinium injection, which carries risks for patients with kidney problems. Additionally, the project implements uncertainty quantification through Monte Carlo Dropout, addressing a critical research gap in medical image synthesis.

## 1. Introduction

### 1.1 Problem Statement
Contrast-enhanced MRI using gadolinium-based agents is essential for detecting brain tumors and other abnormalities. However, gadolinium injection carries risks, particularly for patients with renal impairment. Virtual contrast generation using deep learning can provide the diagnostic benefits of contrast-enhanced imaging without the associated risks.

### 1.2 Research Gap
Existing medical image synthesis methods lack robust uncertainty quantification. In clinical settings, understanding model confidence is crucial for reliable decision-making. This project addresses this gap by implementing Monte Carlo Dropout for pixel-wise uncertainty estimation.

### 1.3 Objectives
- Synthesize T1CE images from T1, T2, FLAIR modalities
- Implement uncertainty quantification for predictions
- Optimize inference speed for clinical deployment
- Provide comprehensive evaluation metrics
- Develop interactive interface for clinical use

## 2. Methodology

### 2.1 Dataset
- **Source**: BraTS2020 Training Data
- **Patients**: 266 (after filtering for missing files)
- **Total Slices**: 41,230
- **Train/Val Split**: 80/20 (seed 42)
- **Train Samples**: 32,984
- **Validation Samples**: 8,246

### 2.2 Model Architecture

#### Attention U-Net
- **Spatial Dimensions**: 2D
- **Input Channels**: 3 (T1, T2, FLAIR)
- **Output Channels**: 1 (T1CE)
- **Encoder Channels**: (32, 64, 128, 256, 512)
- **Strides**: (2, 2, 2, 2)
- **Attention Mechanism**: Attention gates in skip connections

The Attention U-Net architecture was chosen for its ability to focus on relevant features while suppressing irrelevant regions, which is crucial for medical image segmentation and synthesis tasks.

### 2.3 Loss Function

#### Hybrid Loss
The loss function combines three components:

1. **L1 Loss**: Measures absolute differences between predictions and targets
2. **SSIM Loss**: Structural similarity for perceptual quality
3. **Edge Loss**: Preserves structural boundaries and edges

```python
total_loss = l1_loss + λ_ssim * ssim_loss + λ_edge * edge_loss
```

This combination ensures both pixel-level accuracy and structural preservation.

- **Batch Size**: 8
- **Epochs**: 50
- **Device**: CUDA (if available) / CPU

### 2.5 Data Preprocessing

## 3. Inference Optimization

### 3.1 Batch Prediction
Traditional slice-by-slice processing requires 155 forward passes per patient. Our batch prediction processes all slices in a single forward pass:

- **Input**: [D, 3, H, W] tensor
- **Single Forward Pass**: Entire volume processed
- **Speed Improvement**: ~10x faster

### 3.2 Mixed Precision
CUDA-enabled automatic mixed precision (AMP) reduces memory usage and increases inference speed with minimal accuracy loss.

### 3.3 Input Normalization
Automatic normalization ensures robust predictions across different intensity ranges:

```python
normalized = (input - input.min()) / (input.max() - input.min() + 1e-8)
```

## 4. Uncertainty Quantification

### 4.1 Monte Carlo Dropout
Monte Carlo Dropout estimates prediction uncertainty by running multiple forward passes with dropout enabled during inference.

**Process**:
1. Enable dropout layers during inference
2. Run N forward passes (default: 10)
3. Calculate mean prediction
4. Calculate standard deviation (uncertainty map)

**Output**:
- **Mean Prediction**: Final synthesized T1CE
- **Uncertainty Map**: Pixel-wise confidence (lower = higher confidence)

### 4.2 Confidence Thresholding
Binary masks can be generated by thresholding the uncertainty map, allowing clinicians to identify regions with low confidence.

## 5. Evaluation Metrics

### 5.1 Metrics Used
- **PSNR (Peak Signal-to-Noise Ratio)**: Measures reconstruction quality (higher is better)
- **SSIM (Structural Similarity Index)**: Measures structural similarity (0-1, higher is better)
- **MAE (Mean Absolute Error)**: Measures average absolute difference (lower is better)
- **MSE (Mean Squared Error)**: Measures average squared difference (lower is better)

### 5.2 Validation Script
The validation script (`training/validate.py`) evaluates the trained model on the validation set and reports average metrics across all batches.
